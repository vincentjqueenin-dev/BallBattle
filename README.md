NOTICE: The foundations and set up to this project were assisted with AI use.
Another NOTICE: This is not the actual game file, I've uploaded that to another repo. On that note, this is not an actual game, it doesn't have sounds, settings or even an exit button! It is a very unpolished project that was just made to get me familiar with game development.
